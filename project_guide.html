方法一：Android Studio 编译（推荐）

  1. 1

    下载安装 Android Studio

    访问 developer.android.com/studio 下载最新版，安装时勾选 Android SDK。

  2. 2

    打开项目

    打开 Android Studio → File → Open → 选择 RandomPicker 文件夹

    💡 第一次打开会自动下载 Gradle 和依赖，需要保持网络连接（约 300MB）
  3. 3

    等待同步完成

    底部进度条跑完即可。如果出现 SDK 版本错误，按照提示点击 Install missing SDK。

  4. 4

    生成 APK

    菜单栏 → Build → Build Bundle(s) / APK(s) → Build APK(s)

    完成后会弹出提示，点击 locate 打开文件夹，APK 位于：

    app/build/outputs/apk/debug/app-debug.apk
  5. 5

    安装到手机

    将 APK 文件传到手机 → 用文件管理器打开 → 点击安装（需开启"允许未知来源"）

方法二：命令行编译（需 JDK + Android SDK）

  1. 1

    安装 JDK 17

    下载安装 Eclipse Adoptium JDK 17，设置 JAVA_HOME 环境变量

  2. 2

    安装 Android SDK

    下载 command line tools，执行：

    sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
  3. 3

    进入项目目录并编译

    cd RandomPicker
gradlew.bat assembleDebug     # Windows
./gradlew assembleDebug        # macOS/Linux
  4. 4

    找到 APK

    编译成功后 APK 在：app/build/outputs/apk/debug/app-debug.apk

GitHub Actions 自动编译配置

在项目根目录创建 .github/workflows/build.yml：

name: Build APK

on: [push, workflow_dispatch]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-java@v3
        with:
          java-version: '17'
          distribution: 'temurin'
      - name: Make gradlew executable
        run: chmod +x gradlew
      - name: Build APK
        run: ./gradlew assembleDebug
      - name: Upload APK
        uses: actions/upload-artifact@v3
        with:
          name: RandomPicker-debug
          path: app/build/outputs/apk/debug/*.apk
